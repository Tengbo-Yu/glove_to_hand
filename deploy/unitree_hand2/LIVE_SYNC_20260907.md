## External host integration

The target additionally uses this systemd drop-in at
`/etc/systemd/system/wuji-hand2@.service.d/99-config-persistence.conf`:

```ini
[Unit]
Requires=deltacollect-config-guard@wuji-%i.service
After=deltacollect-config-guard@wuji-%i.service
[Service]
ExecStartPre=+/usr/bin/python3 /usr/local/libexec/deltacollect-config-guard.py --state /var/lib/deltacollect/config-guard restore
```

This belongs to the separate DeltaCollect deployment. It is documented here,
not installed by this repository: it depends on the external guard service,
script and `/var/lib/deltacollect/config-guard` state. A future target deployment
must account for that guard restoring its own saved configuration.
